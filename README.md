# ArbitrStarokorov
Программы для арбитражного управляющего и его юридической компании.

## Telegram-бот первичной консультации

Готовый бот для Telegram, который ведет клиента по сценарию первичной консультации:
- узнает сумму долга;
- задает квалификационные вопросы по одному за раз;
- объясняет риски и стоимость бездействия;
- предлагает условия (245 000 ₽, скидка 5 000 ₽, рассрочка 20 000 ₽/мес);
- запрашивает фото паспорта и номер телефона.

## Быстрый запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте переменную окружения:
   ```bash
   export TELEGRAM_BOT_TOKEN="<ваш_токен>"
   ```
   Или используйте файл `.env` по примеру `.env.example`.
3. Запустите бота:
   ```bash
   python bot.py
   ```

## Важно по безопасности

Не храните токен бота в репозитории. Если токен уже публиковался, лучше перевыпустить его через BotFather.
